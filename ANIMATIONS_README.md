### 2. 🎯 Псевдоклассы (9+ различных)

- `:hover` - эффекты при наведении (используется на всех интерактивных элементах)
- `:active` - эффекты при нажатии (кнопки, ссылки навигации, социальные иконки)
- `:focus` - стили для фокуса клавиатуры (доступность)
- `:nth-child()` - чередование стилей для элементов
- `:first-child` - стили для первого элемента
- `:last-child` - стили для последнего элемента
- `:visited` - стили для посещенных ссылок
- `:nth-child(odd)` - стили для нечетных элементов
- `:nth-child(even)` - стили для четных элементов
- `:not()` - исключение элементов из стилизации

### 3. ✨ Псевдоэлементы (16+ использований)

- `::selection` - стилизация выделенного текста
- `::before` - декоративные элементы (стрелки, иконки, линии, блики)
- `::after` - подчеркивания, свечения, значки
- `::first-letter` - увеличенная первая буква заголовков
- `::first-line` - стилизация первой строки параграфов

## 🎨 Типы используемых анимаций

### Transition (плавные переходы)
- Изменение цвета при наведении
- Трансформации (scale, translate, rotate)
- Изменение теней и границ
- Фильтры (blur, brightness, saturate)

### Transform (трансформации)
- `translateX()` / `translateY()` - перемещение
- `scale()` - масштабирование
- `rotate()` - вращение
- `skew()` - искривление

### Animation (@keyframes)
- Градиентные переходы
- Пульсация
- Мигание
- Плавающее движение
- Волны
- Комплексные последовательности

### Кривые Безье
Используются функции:
- `cubic-bezier(0.68, -0.55, 0.265, 1.55)` - отскок
- `cubic-bezier(0.175, 0.885, 0.32, 1.275)` - плавное ускорение
- `ease-in-out`, `ease-out`, `ease-in` - стандартные функции

## 📱 Адаптивность

### Планшеты (max-width: 768px)
- Уменьшена интенсивность анимаций
- Отключены тяжелые floating-анимации
- Упрощены эффекты transform

### Мобильные устройства (max-width: 320px)
- Большинство анимаций отключено для производительности
- Сохранены только базовые hover-эффекты
- Упрощены трансформации

### Доступность
Добавлена поддержка `prefers-reduced-motion` для пользователей с ограниченными возможностями:
```css
@media (prefers-reduced-motion: reduce) {
    /* Все анимации минимизированы */
}
```
